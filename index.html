HTML

HTML — це мова для розмітки документів для перегляду їх на екрані монітора у вікні браузера. Документ, описаний за допомогою мови розмітки HTML, — це текстовий файл, який можна створити й редагувати у найпростішому редакторі (Блокнот, Notrpad++, Kate тощо). Він містить містить різні елементи: заголовки, абзаци, малюнки, таблиці та інші. Кожний елемент задають вказівкою мови HTML, яку називають тегом.

CSS

CSS (Cascading Style Sheets) є мовою стилів, що використовується для опису зовнішнього вигляду веб-сторінок, написаних мовою розмітки HTML. Вона визначає, як елементи HTML повинні відображатись у браузері, включаючи кольори, шрифти, розміри, положення, межі та інші атрибути стилю.

JS

JavaScript — це сценарна прототипна мова програмування з динамічною типізацією.
